# Mobile 项目角色映射

> 本文件定义 mobile 项目的角色映射。
> 角色定义的唯一真源：`~/.agents/skills/role-*/SKILL.md`
> 项目内只维护映射关系和工作流，不复制人格内容。

## 单一事实源

- **完整角色定义**：`~/.agents/skills/role-<role>/SKILL.md`
- **项目内薄路由**：`/Users/weiran/mobile/.claude/skills/role-router/SKILL.md`

## 角色映射

### `ui`（绘心）

- 中文名：绘心
- 全局定义：`~/.agents/skills/role-ui/SKILL.md`
- 适用任务：页面结构、交互、视觉设计、样式、响应式布局
- 本项目应用：邀请明细、团队管理、主页的视觉设计与样式优化

### `pm`（明策）

- 中文名：明策
- 全局定义：`~/.agents/skills/role-pm/SKILL.md`
- 适用任务：需求分析、功能优先级、业务流程设计、PRD
- 本项目应用：团队管理流程、邀请机制的业务设计

### `dev`（码匠）

- 中文名：码匠
- 全局定义：`~/.agents/skills/role-dev/SKILL.md`
- 适用任务：开发实现、修 bug、调试、重构
- 本项目应用：页面功能开发、模态框实现、表单验证

### `arch`（架构师）

- 中文名：架构师
- 全局定义：`~/.agents/skills/role-arch/SKILL.md`
- 适用任务：技术架构、页面结构设计、数据流设计
- 本项目应用：多页面应用的导航架构、数据管理方案

## 项目专有工作流

### mobile-dev（轻量开发）

用于小改动、样式调整、功能补充。

- 触发词：快速改、调整一下、修个细节、加个功能
- 流程：读文件 → 确认改动范围 → 直接修改 → 验证
- 允许工具：Read, Write, Edit, Bash

## 使用原则

1. 先看**任务上下文**，再决定是否需要角色视角
2. 不复制角色定义到项目内
3. 项目内只维护**工作流 skill** 和 **映射关系**
4. 复杂任务使用完整角色定义；简单任务不需要角色

## 层级指南

| 任务复杂度 | 是否需要角色 | 推荐 Skill |
|----------|----------|----------|
| 简单修改（样式、文案） | ✗ | 无需 role |
| 小功能补充（加按钮、表单） | △ | mobile-dev |
| 新页面设计 | ✓ | role-ui + role-dev |
| 需求分析/业务流程 | ✓ | role-pm |
| 架构调整 | ✓ | role-arch |
